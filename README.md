# 时间间隔计算器（Time Interval Calculator）

一个**纯前端、移动端优先**的时间间隔计算工具。输入锚点时间与固定间隔，即可批量推算按固定周期重复发生的事件时间点，内置多事件管理、标记点、时差修正、倒计时、条件筛选，以及基于剪贴板的备份与选择性恢复。

无需后端、无需构建、无第三方依赖，三个静态文件即可在任意浏览器或静态托管上运行。

## 功能特性

- **固定间隔批量推算**：给定锚点时间与间隔时长，一次生成任意数量的事件时间点（开始 / 结束）。
- **多事件独立管理**：最多支持 20 个事件，每个事件独立保存配置，可在下拉中快速切换、新建、停用 / 启用、删除。
- **两种计算模式**：
  - *按次数*：从锚点向后计算 N 次；
  - *按范围*：直接指定开始次数与结束次数。
- **标记点**：每个事件最多 3 个标记点，基于开始时间偏移计算（如服药、巡检等节点）。
- **时差修正**：支持“设备时间 − 系统时间”的偏移，可选择仅作用于倒计时，或同时作用于列表与倒计时。
- **倒计时卡片**：自动识别“进行中 / 待开始”事件，进行中可显示距下一标记点或结束的剩余时间；点击数字直接定位到对应行。
- **条件筛选**：按时间段、单 / 双日、星期（可多选）、次序范围组合筛选，条件按事件独立缓存。
- **两种结果视图**：“看全部”展示完整时间表，“看单日”按日期前后翻页、跨日事件在起止两日都显示。
- **时间状态着色**：已过去（灰）、进行中（红）、最近的未来事件（蓝），每秒自动刷新。
- **剪贴板备份 / 恢复**：备份内容复制到剪贴板即可跨设备迁移；恢复时可**勾选部分事件**，不再强制全部覆盖。
- **版本检查**：首次使用展示注意事项，版本升级展示更新内容。
- **完全本地化**：不请求网络、不收集数据、无任何第三方依赖。

## 快速开始

### 方式一：直接打开

1. 下载或克隆本仓库；
2. 用浏览器打开 `index.html` 即可使用（建议使用手机浏览器或开启浏览器的设备模拟模式以获得最佳体验）。

### 方式二：静态托管 / GitHub Pages

将仓库目录部署到任意静态文件服务器即可，例如 GitHub Pages、Netlify、Vercel、Nginx 等。本项目无构建步骤。

```bash
# 本地起一个静态服务器（任选其一）
python3 -m http.server 8080
npx serve .
```

然后访问 `http://localhost:8080`。

> 页面为移动端优先设计，最大宽度 500px 居中，在桌面浏览器上会以居中卡片形式呈现。

## 使用说明

### 1. 新建与切换事件

- 在顶部（配置页）或结果页的“下拉切换”中点击，选择“新建事件”，最多 20 个。
- 下拉内置排序栏，可按 **状态 / 名称 / 间隔 / 建立顺序** 排列，并可通过方向按钮切换正序、倒序。
- “事件管理”模式下可对事件执行停用 / 启用、删除。

### 2. 配置参数

| 参数 | 说明 |
| --- | --- |
| 事件名称 | 最多 8 个汉字 |
| 间隔时长 | 相邻两次事件之间的间隔（时:分:秒） |
| 开始时间 | 锚点日期与时间 |
| 持续时间 | 每次事件的持续时长 |
| 该次次数 | 锚点时间对应的是第几次 |
| 计算模式 | 按次数 / 按范围 |
| 计算次数 / 起止次数 | 决定要生成的时间点范围 |

填写完成后点击“确定”，会自动计算并跳转到结果页。

### 3. 标记点与时差修正（可选）

- 展开“标记点与时差”折叠区，可添加最多 3 个标记点（名称 ≤ 4 字 + 相对开始时间的偏移）。
- 时差修正用于对齐设备时间与本地系统时间，应用范围可选：关闭 / 仅倒计时 / 列表 + 倒计时。

### 4. 结果页

- **找到最近一次**：优先定位正在进行中的事件，否则定位下一次未发生事件。
- **筛选**：打开筛选面板组合条件，按钮上的角标表示当前存在生效的筛选条件。
- **看全部 / 看单日**：单日视图可通过“前一日 / 后一日”或点击日期按钮跳转。
- **倒计时卡片**：进行中显示距下一标记点 / 结束的时间，待开始显示距开始的时间；点击数字定位到目标行。

### 5. 筛选规则

- **时间段**：事件开始或结束时间任意一个落在范围内即通过；
- **单双日**：开始日或结束日任意一个符合即通过；
- **星期**：开始日或结束日任意一个匹配选中星期即通过（可多选）；
- **次序范围**：按次序号筛选；
- 多个条件之间为“且”关系。

## 数据存储与隐私

本工具完全在本地浏览器中运行，所有数据通过浏览器的 `localStorage` 保存，**不会上传到任何服务器，也不请求网络**。

使用到的存储键：

| 键名 | 内容 |
| --- | --- |
| `tc_events` | 事件列表（id 与名称） |
| `tc_event_{id}` | 单个事件的完整配置 |
| `tc_currentEvent` | 当前选中的事件 id |
| `tc_sort` | 下拉排序偏好 |
| `tc_app_version` | 已确认的应用版本号（用于首次 / 升级判断） |

清除浏览器数据或站点存储会同时删除上述配置，请提前做好备份。

## 备份与恢复

备份与恢复均通过**剪贴板**完成，无需下载或选择文件，便于在备忘录、聊天工具或不同设备之间迁移。

- **备份**：在“关于”页点击“备份数据”，系统会将“可读概览 + JSON 数据”（不含计算结果）复制到剪贴板，请立即粘贴到备忘录或文件中妥善保存。若自动复制失败，会弹出“手动复制”面板。
- **恢复**：点击“恢复数据”，先尝试自动读取剪贴板；若浏览器不允许自动读取，则弹出粘贴面板由你手动粘贴。
- **选择性恢复**：解析备份后会列出其中的事件，可逐项勾选：
  - 与本地**同 id** 的事件标记为“覆盖”；
  - 本地不存在的事件标记为“新增”；
  - 未勾选的本地事件保持不变。
- 恢复后，启用状态的事件会自动重新计算时间表。

> 安全提醒：请勿恢复来源不明或被篡改过的备份内容。

## 浏览器兼容性

- 推荐使用任意现代浏览器（Chrome / Edge / Firefox / Safari）及基于 Chromium 的移动端 WebView。
- 时间 / 日期选择使用内置的三列滚轮选择器，不依赖原生 `input[type=time]`，在移动端表现一致。
- 剪贴板功能优先使用 [Clipboard API](https://developer.mozilla.org/docs/Web/API/Clipboard_API)，在非安全上下文或未授权时会自动降级：
  - 复制：降级为隐藏文本框 + `execCommand('copy')`，仍失败则提供手动复制面板；
  - 读取：`navigator.clipboard.readText()` 不可用时，提供手动粘贴面板。
